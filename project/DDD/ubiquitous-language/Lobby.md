
## lobby-context
| Term          | BuildingBlock-DDD | Definizione                                                                                                                                                                                                          |
|---------------|-------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Lobby         | Value-Object      | Rappresentzione di una lobby alla quale i Player possono fare Join salvo raggiungimento del un numero masismo di Player (LobbyCapacity) sia Friend che non. Raggiunta la capacità massima diventa un Match/GameView. |
| Match         | Value-Object      | Rappresentazione di un Match in corso alla quale è possibile fare Join solo come Watcher.                                                                                                                            |
|               |                   |                                                                                                                                                                                                                      |
| LobbyJoined   | Domain-Event      | Evento generato quando un Player effettua il Join ad una Lobby.                                                                                                                                                      |
| WatcherJoined | Domain-Event      | Evento generato quando un Player effettua il Join ad un Match.                                                                                                                                                       |
|               |                   |                                                                                                                                                                                                                      |
| - Term -      | - Tipology -      |                                                                                                                                                                                                                      |
| PublicLobby   | Concept           | Lobby pubblica visibile indistintamente da tutti i Player alla quale è possibile fare Join.                                                                                                                          |
| FriendLobby   | Concept           | PublicLobby il cui LobbyMaster è un Friend.                                                                                                                                                                          |
| InvitedLobby  | Concept           | Lobby privata alla quale si è stati invitati e il LobbyMaster è un Friend.                                                                                                                                           |
| JoinRequest   | Concept           | Invito alla lobby da parte di un Friend.                                                                                                                                                                             |
| LobbyCapacity | Concept           | Capacità massima di Player contenibili dalla Lobby.                                                                                                                                                                  |
| LobbyMaster   | Concept           | Nome/Nickname del Player che detiene la proprietà della Lobby.                                                                                                                                                       |
| LobbyName     | Concept           | Nome della Lobby.                                                                                                                                                                                                    |
| JoinMark      | Concept           | Elemento che indica ad un Player che è stato invitato alla Lobby da un Friend.                                                                                                                                       |
|               |                   |                                                                                                                                                                                                                      |
| WatchMatch    | Azione            | Azione di Join ad un ActiveMatch come Watcher                                                                                                                                                                        |
| JoinLobby     | Azione            | Azione di Join ad una Lobby come Player in attesa dell'inizio del Match.                                                                                                                                             |
| SearchLobby   | Azione            | Azione di ricerca anche con filtri semplici (es. join come Watcher o Player) per trovare Match in corso a cui assistere oppure Lobby a cui aggiungersi.                                                              |
|               |                   |                                                                                                                                                                                                                      |

## pregame-lobby-context
| Term             | BuildingBlock-DDD | Definizione                                                                                                                                                                                                                  |
|------------------|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Lobby            | Aggregate-Root    | Sala d'attesa virtuale creata dal LobbyMaster dove i Player si raccolgono prima dell'inizio del Match.                                                                                                                       |
| GameSettings     | Value-Object      | Insieme di tutte le configurazioni del Match (BombAmount, DefuseAmount, TurnTimer, LobbySize, LobbyName, CardBack e Visibility)                                                                                              |
| DeckMatch        | Value-Object      | Deck scelto per il match. Può essere composto da uno o più Deck e/o CustomDeck.                                                                                                                                              |
| Deck             | Value-Object      | Mazzo disponibile per essere utilizzato nella composizione del DeckMatch.                                                                                                                                                    |
| CustomDeck       | Value-Object      | Deck personalizzato disponibile per essere utilizzato nella composizione del DeckMatch.                                                                                                                                      |
| LobbyMaster      | Value-Object      | Player che crea la Lobby e ne detiene la proprietà quindi ha il controllo delle GameSettings e dell'inizio anticipato del Match.                                                                                             |
| JoinedPlayer     | Value-Object      | Player (anche Friend) che ha fatto Join alla Lobby in attesa dell'inizio del Match.                                                                                                                                          |
| Friend           | Value-Object      | Player amico a cui è possibile inviare un JoinRequest.                                                                                                                                                                       |
|                  |                   |                                                                                                                                                                                                                              |
| JoinRequest      | Entity            | Invito di Join al Match ad un Friend da parte del LobbyMaster.                                                                                                                                                               |
|                  |                   |                                                                                                                                                                                                                              |
| LobbyOpened      | Domain-Event      | Evento generato all'apertura della Lobby a tutti i Player. La Lobby viene resa Public.                                                                                                                                       |
| LobbyClosed      | Domain-Event      | Evento che indica che la Visibility della Lobby è passata da Public a Private. Questo evento viene causato quando il LobbyMaster torna indietro per modificare le configurazioni oppure quando il LobbySize viene raggiunto. |
| MatchStarted     | Domain-Event      | Evento di inizio Match dovuto dal raggiungimento della LobbySize o per volonta del LobbyMaster.                                                                                                                              |
| JoinRequestSent  | Domain-Event      | Evento di avvenuto invio del JoinRequest.                                                                                                                                                                                    |
|                  |                   |                                                                                                                                                                                                                              |
| - Term -         | - Tipology -      | //                                                                                                                                                                                                                           |
| StartMatchPolicy | Policy            | Regole e logica di controllo per il corretto avvio del Match. Se la LobbySize non è risepttata il Match non può avere inizio.                                                                                                |
| Public           | State             | Stato che assume la Lobby quando è visibile a tutti i Player (non solo Friend) i quali possono fare Join.                                                                                                                    |
| Private          | State             | Stato che assume la Lobby quando è invisibile agli altri Player ma solo ai Friend invitati.                                                                                                                                  |
|                  |                   |                                                                                                                                                                                                                              |
| Visibility       | Concept           | Visibilità della Lobby rispetto a tutti i Player della piattaforma. Può essere Public oppure Private.                                                                                                                        |
| LobbySize        | Concept           | Quantità massima di Player (Friend e non) che possono partecipare (Join) al match.                                                                                                                                           |
| CardBack         | Concept           | Grafica applicata al retro delle carte del DeckMatch.                                                                                                                                                                        |
| TurnTimer        | Concept           | Valore numerico che indica il tempo massimo di durata di un turno del Match per ciascun Player.                                                                                                                              |
| BombAmount       | Concept           | Valore numerico intero che indica qunate bombe aggiuntie inserire nel DeckMatch rispetto al default.                                                                                                                         |
| DefuseAmount     | Concept           | Valore numerico intero che indica quanti disinneschi aggiuntivi inserire nel DeckMatch rispetto al default.                                                                                                                  |
| MatchName        | Concept           | Nome assegnato alla Lobby.                                                                                                                                                                                                   |
| WaitingPhase     | Concept           | Situazione in cui il LobbyMaster attende che i Player facciano Join.                                                                                                                                                         |
|                  |                   |                                                                                                                                                                                                                              |
| JoinRequestSend  | Action            | Invio di un JoinRequest ad un Friend.                                                                                                                                                                                        |
| LobbyCreate      | Action            | Creazione di una Lobby.                                                                                                                                                                                                      |
| LobbyDelete      | Action            | Cancellazione della Lobby da parte del LobbyMaster.                                                                                                                                                                          |
| StartMatch       | Action            | Avvio del Match nel caso siano verificate le StartMatchPolicy. Questa azione provoca l'evento MatchStarted.                                                                                                                  |
| DeckAdd          | Action            | Aggiunta delle carte del Deck selezionato al DeckMatch.                                                                                                                                                                      |
| DeckRemove       | Action            | Rimozione delle carte del Deck precedentemente aggiunte dal DeckMatch.                                                                                                                                                       |
| CustomDeckAdd    | Action            | Aggiunta delle carte del CustomDeck selezionato al DeckMatch.                                                                                                                                                                |
| CustomDeckRemove | Action            | Rimozione delle carte del CustomDeck precedentemente aggiunte dal DeckMatch.                                                                                                                                                 |
|
